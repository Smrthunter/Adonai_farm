# Adonai Farm Website

A responsive static website for Adonai Farm, Chepsir, Kericho.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy
1. Create a GitHub repository.
2. Upload these files.
3. Connect the repository to Netlify or Vercel.
4. Deploy.
5. Add the farm's custom domain when ready.

## Before launch
- Replace the Unsplash image URLs with Adonai Farm's own photos.
- Confirm all business facts, phone numbers, email and service descriptions with the owner.
- Add the final logo and social media links.
